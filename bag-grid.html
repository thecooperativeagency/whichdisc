Placement rules

  • Row from speed only (glide → carry tag)
  • Col from turn + fade (fade-aware, not turn+fade sum)
  • VOS if fade ≥ 3.5 and turn ≥ −0.5
  • OS if fade ≥ 3 and turn ≥ −1 and stab ≥ 1.5
  • US if turn ≤ −2, or turn ≤ −1 with fade ≤ 1
  • else STR

What the grid says

  • OS ladder is clean: X3 → Banshee → Orc → Firebird
  • Mid STR stacked: Atlas + Mako3
  • Flip-D stacked: Mystere + Archon (same cell by design)
  • No speed-12+ Distance row — max D sits Hybrid 10–11
  • Empty that matter later: Mid US, Fairway US, Hybrid STR
